# DevOps Собес

Учебный веб‑тренажёр для подготовки к DevOps‑собеседованиям: **281 вопрос** в **18 темах**, роадмап, тестовые собеседования с результатом, прогресс в браузере. Работает полностью в браузере, без бэкенда.

## Возможности
- 🗺 **Роадмап** — системный путь от основ до облака, с прогрессом по этапам.
- 🎓 **Тестовые собеседования** — вопрос → эталонный ответ → самооценка → результат с разбором по темам.
- 🎴 **Карточки** и 📚 просмотр по темам, поиск по вопросам и ответам.
- Прогресс, избранное и «на повторение» хранятся локально (localStorage). Тёмная/светлая тема.

## Источник контента
Вопросы и ответы взяты из открытого репозитория **[Swfuse/devops-interview](https://github.com/Swfuse/devops-interview)**. Этот проект — лишь оболочка для удобной проработки; весь контент принадлежит авторам источника. Если вы автор и хотите изменить условия использования — напишите, уберу.

## Запуск локально
Открыть `index.html` в браузере, либо:
```bash
python3 -m http.server 8899
# http://localhost:8899
```

## Пересборка данных из источника
```bash
git clone https://github.com/Swfuse/devops-interview
python3 -I build.py devops-interview/interview.md   # пересоберёт data.js
```

Подсветка кода (`marked`, `highlight.js`) подключается с CDN.
